# Glass Photo Style

[English](README.en.md)

将用户上传的照片转换成干净、高清、具有模型感的渲染玻璃微缩模型。

这是一个独立的 Codex Skill，适合把店铺、建筑、街景、地标、物品或产品照片重新表现为由玻璃板、玻璃块和玻璃小部件组装而成的精密收藏模型。

## 示例方向

### Costa Coffee

保留店铺门面、酒红色雨棚、招牌、花箱、桌椅和室内灯光。地面和背板可以是一整块有厚度的玻璃，招牌和字母保持独立清晰。

### 天坛

保留三层圆形屋顶、蓝绿色装饰、红色建筑主体、金色顶部、台基、栏杆和中轴线。屋顶和台基使用透明与磨砂玻璃混合材质，强调叠层结构和玻璃边缘。

## 视觉方向

- 轻盈、清透、柔和、精密的 Liquid Glass-inspired 质感
- 大面积地面或背板可以是一整块厚玻璃
- 大面积表面使用平滑的半透明磨砂玻璃，边缘、门窗和倒角使用清透玻璃
- 玻璃需要有厚度、倒角、轻微折射和干净的边缘高光
- 颜色保留原照片层次，避免整体灰白或变成彩色水晶
- 主要部件彼此分离，有清晰轮廓、缝隙和接触阴影
- 视角跟随上传照片实际展示的正面、侧面、内部和前后关系；接近正视图时校正为稳定的正面平行透视
- 透视固定使用平行透视，同时修正广角畸变、建筑线条倾斜、底座歪斜和不必要的透视收缩
- 招牌、Logo 和文字使用独立凸起的实体部件，保持清晰可读
- 输出高清图像，保持边缘、文字、建筑细节和部件连接清晰
- 使用高端工作室产品展示构图：主体水平居中，完整显示左右最外侧结构
- 画面四周至少保留 20% 的空余，不贴边、不裁切
- 使用干净背景、柔和工作室灯光、精确高光和清晰接触阴影

## 使用方式

```text
把这张照片转换成干净的渲染玻璃微缩模型，保留原来的构图，使用透明与磨砂玻璃混合材质，保持高清细节和上下留白。
```

## 不能做的

- 不能把结果做成普通照片加玻璃滤镜
- 不能让所有部件使用相同透明度
- 不能让招牌、字母、屋顶、墙体或小部件融合在一起
- 不能使用油亮、油膜、彩虹水晶或糖果塑料效果
- 不能用全局模糊、雾气、强 Bloom 或严重折射掩盖细节
- 不能让文字和 Logo 变得模糊或不可读
- 不能裁切模型最高点、底座、左右最外侧结构或主要建筑结构
- 不能把明显斜视的照片强行转换成正视图或三分之四视图
- 不能让接近正视图的底座、地面或主要水平线保持歪斜
- 不能让主体任何一侧的安全空间少于 20%
- 不能把所有照片强行转换成正视图或三分之四视图
- 不能让主体、底座、投影或任何主要物体刚好触碰画布边缘
- 不能为了高清加入噪点、过度锐化或伪细节
- 不能随意新增建筑、道具、包装、透明展示盒、水印或随机文字
